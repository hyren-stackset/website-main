What we do

One small team, the whole stack.

From the first wireframe to the App Store listing to the on-call rotation, every product we ship is designed, built and operated in-house.

Consumer apps

Native-feeling iOS and Android apps built with React Native and Expo, shipped through TestFlight and Google Play, with over-the-air updates so fixes reach phones in minutes.

Product platform

Postgres with row-level security, realtime channels, media pipelines, push notifications, and the integration endpoints that keep internal data off the public internet.

Design systems

Our own component library with motion, theming (light, dark and more), accessibility built in, and the discipline to keep every screen consistent as products grow.

Shelfie: your shelf, your people.

Shelfie is a mobile-native beauty discovery and social collection app. Build collections of the products you actually use, follow friends and creators, decode ingredient lists, and keep up with every launch, all in one place.

  • 01
    Collections & shorts

    Curate public, followers-only or private collections with sections, hashtags and covers. Pair them with vertical reels and photo posts tagged to real products.

  • 02
    INCI ingredient analyzer

    Paste any ingredient list or pick a product from a catalogue of 1,300+ to see categories, likely concentration, flags, and side-by-side comparisons.

  • 03
    Socials

    Realtime direct messages, group chats, group collections and a follow graph with invite codes, plus push notifications when it matters.

  • 04
    Products & launches

    Browse 290 categories and 300+ brands, track upcoming launches on a release calendar, and request anything we're missing by pasting a link.

Core security infrastructure

Built so the database is never on the internet.

Every Stackset product ships on the same hardened platform. Clients never hold a database connection string. They talk to a narrow integration layer that authenticates, authorises and shapes every request before anything touches storage.

Untrusted
iOS / Android / Web clients short-lived tokens only
direct DB connection no route · refused
TLS 1.3 · JWT · rate limits
Edge
Integration service endpoints auth · validation · policy
mTLS inside the private network
Private network
Containerised services one job each · least privilege
Media & extraction workers sandboxed · egress-filtered
Postgres + object storage row-level security · encrypted at rest
SSO (OIDC) for every internal console · audit-logged

Integration service endpoints

Apps call purpose-built endpoints, not tables. Each endpoint validates input, checks the caller's identity and policy, and returns only the fields that screen needs. Internal database hosts have no public route, so a leaked client build or a malicious agent probing our edge finds nothing to connect to.

Single sign-on everywhere

Every internal console, dashboard and admin tool sits behind SSO with OpenID Connect and enforced multi-factor authentication. Access is role-based and reviewed; leaving the team revokes everything in one place. End users get the same care: Sign in with Apple, Google, or a one-time email code. We never see or store passwords in plain text.

Containerised applications

Each service runs in its own container with a read-only filesystem, a non-root user, pinned dependencies and an explicit egress allow-list. Workers that touch untrusted content, such as link extraction and media transcoding, are isolated from anything holding user data.

Row-level security as the last line

Even behind the gateway, the database enforces per-row policies tied to the authenticated user. A bug in one endpoint cannot read another person's private collection, message or profile.

Secrets that never sit still

Credentials are minted at deploy time, scoped to one service, rotated automatically and injected at runtime. Nothing sensitive lives in a repository, a build artefact or a developer laptop.

Encryption and auditability

TLS 1.3 in transit, AES-256 at rest, signed and immutable deploy snapshots, and structured audit logs for every privileged action. If something looks wrong we can see exactly who did what, and roll back in under a minute.
